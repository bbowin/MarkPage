## 专项说明

1. **钢琴音色**：早期尝试的 d-piano / Salamander 钢琴采样为 **CC-BY-3.0**（需署名，且与"免署名商用"诉求不符），**已否决移除**；现使用**纯 MIT 自研 WebAudio 振荡器合成**，零采样版权风险。
2. **人声 / 唱歌**：免费可商用的真人中文歌声采样不存在；唱歌模块已移除，仅保留电子琴式钢琴合成。
3. **字体**：KaTeX 字体（woff2）随 KaTeX MIT 分发；UI 使用系统字体栈，无内置商业字体。
4. **图标**：全部为自绘 SVG / Emoji / 文本图标（青简蓝圆 logo、文件 / 文件夹 / 按钮图标等），无第三方图标库。
5. **朗读音源**：系统 TTS 与 Edge 在线自然语音为浏览器内置能力（免费、无需申请）；Azure 语音需用户自备密钥；本地音库路径由用户配置；**不打包任何第三方语音采样**。
6. **网络电台**：`radio` 模块不内置任何直播源，频道数据由用户自行添加并仅存 localStorage；播放依赖远端服务器 CORS 许可。
7. **演示数据**：内置演示文档中的 GDP / 算力 / PPM 等数值均为**虚拟演示数据**，文档内已声明，正式文稿发布前须核验官方原文。
8. **浏览器商标**：README / 文档中对 Chrome / Edge 等的提及仅为兼容性指引，不使用其商标做宣传。
